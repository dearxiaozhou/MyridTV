# 运镜动画预设插件 2.2

入口：**画布 → 新建3D预演节点 → 提示词下方参数区**。

用户选择运镜名称，设置时长、起始景别、焦距与幅度，再生成预览视频。幅度留空自动计算。主体可选X_Bot、Y_Bot或双人；不需要填写相机XYZ、人物XYZ或瞄准坐标。

当前界面自动采用预设节奏、居中构图、人物瞄准和随主体位移；结束景别由运镜距离决定，不再要求填写这几组参数。协议字段仍用于旧工程兼容。推近/拉远会随裁切范围调整瞄准高度，保留头部空间。修改焦距会重新匹配起始机距，维持所选景别。

## 内嵌参数、提示词资产与多人站位

所有预演控件和运行按钮均位于提示词下方。第一排为等宽的比例/时长/运镜/焦距；下一排为取景、角度和资产开关。没有弹窗、保存或取消按钮，修改自动保留。单段动作自动沿用镜头时长；动作组合以两张紧凑卡片一排显示，每张卡的动作选择宽112px，数字框64–88px。小宽度下改为单列保证可编辑。

资产只有一个开关：关闭时忽略资产文字、不使用场景；开启时从共用提示词框识别资产名称、位置或已有工程。例如：

```text
人物走路。
资产：长椅，左后方；茶几，右侧
```

已有完整场景写“工程：本地 .blend 路径”（也支持画布工程的/assets/引用）。已有单件模型可写“资产：椅子”后换行“模型：本地 .glb/.obj/.fbx/.blend路径”。支持“资产 | 名称 | 类别 | [x,y,z] | [宽,深,高]”旧结构行；常见物件名称也可直接从普通描述中识别。尺寸默认匹配类别，可用2×1×0.8等写法；未提供模型时建立结构草模。它是本地规则解析，不声称支持任意复杂自然语言场景建模。资产关闭不会清空提示词，重新开启可恢复。

人物站位仍在可展开的俯视图中，最多8人，支持命名、X/Y模型、朝向及执行动作/静态站立/静态坐姿。可选择任意人物或多人整体。不同人物使用不同动作时间线尚未提供。资产由提示词建立后也可在图中拖动微调位置。

精确机位高度放在微调中。平视/仰拍/俯拍/鸟瞰可以直接选择，不要求填写XYZ。底层独立JSON协议保留结构化场景参数以兼容已有工程和CLI；原场景工程不会覆盖。

左下角工具栏末尾新增“输入框自适应”。这个开关只控制位置。开启时，面板会自动避让窗口边缘和小地图；关闭时，面板始终居中锚定所选节点下方，向下展开，允许超出窗口可见区域。它不改变宽度、文字大小、缩放补偿或手动调整高度的方式。所有共用节点输入面板生效，本机偏好持久化。

## 主体动作与拍摄目标

动作独立于运镜，可顺序组合站立、走路、跑步、停下、坐下、起身。每段设置秒数；走跑可设置0–50米和前/后/左/右（场景初始+Y/-Y/-X/+X）。距离在该段时长内完成，余下镜头时间保持最后状态。动作合计不得超过镜头时长。提供走→跑→停→坐下一键组合。行走/跑步/坐下/起身来自本地Mixamo动作库，预先缓存X/Y骨架动作，使用原生NLA片段和交接混合，可在工程中修改。

起镜和结束可各自指定按景别自动、头部、胸部、腰胯、脚部；结束默认保持起镜部位。瞄准可跟随选定主体部位或固定世界落点。正/背/左侧/右侧决定初始拍摄方位。相机默认叠加主体位移，保证运动中的脚部特写保持距离。相机沿预设的运动仍保留。多人时可选择任意具名人物或多人整体为拍摄对象。

环绕支持完整360度，起点和终点可重合；曲线保留完整环路，不以终点距离误判为静止。

## 已有30项资产的使用

原始 `30种摄像机运动.blend` 不覆盖。按实际求值的相机世界位置和朝向筛选，19项进入 `tygg_previs/assets/motion_cameras.blend`，11项无实际相机运动的效果从主列表移除。完整审计及源文件SHA256位于 `tygg_previs/assets/motion_catalog.json`。

保留：慢推进、摇镜揭示、中景跟拍、穿梭、超现实、希区柯克变焦、慢速拉出、上摇、下摇、水平摇镜、横移、渐进变速横移、吊臂上升、吊臂下降、第一人称行走、遮挡揭示、穿飞、窥视推进、180度环绕。画布中部分名称简化为推近、拉远、环绕、升高等。

移除：慢镜头感、背景虚化、低机位、高机位、浅景深、转移焦点、蒙太奇、冲击变焦、正反打、鱼眼镜头、前景遮挡转场。它们只有静态机位、光学变化、多机位陈列或物体移动，没有实际相机机位/朝向变化。希区柯克变焦保留，因为它包含真实推进，并配合反向变焦。

## 架构

- `web/motion.js`：简洁的画布参数面板；旧起落幅编辑器不再作为主入口。
- `plugin.py`：本地任务、取消、排队、结果适配；不调用LLM。
- `motion_previs_cli.py`：可独立运行的Blender后台入口。
- `tygg_previs/motion_model.py`：无Blender依赖的参数与预设协议。
- `tygg_previs/actor_motion.py`：独立动作组合、分段位移与原生NLA时间曲线。
- `tygg_previs/motion_engine.py`：约束摄像机、自动取景、视频导出和更新。
- `assets/motion_cameras.blend`：筛选后的实际摄像机资产。
- `assets/walk_actions.blend`：按X_Bot/Y_Bot绑定分别准备的现成行走循环；跟随类复用，不逐镜重做。

相机使用真实Follow Path或固定机位约束、原资产的瞄准约束，以及稳定上轴约束。相机本体没有位置/旋转动画关键帧，运动进度只有两个键。普通改参复用上次的预演工程和人物；切换预设只更新自身的相机结构，切换主体时才新建对应人物资产。

主协议：

```json
{"schema_version":"motion/1.0","preset":"02_慢推进","duration":4,"framing":"full","lens_mm":50,"amount":null,"subject":"x_bot","direction":"left","pace":"preset","composition":"center","end_framing":"auto"}
```

时长1–30秒；焦距18–135mm；幅度单位按预设自动切换为米或度。`subject`为`x_bot/y_bot/both`；`framing`为`wide/full/medium/close/detail`。完整默认值与校验由motion_model提供。

独立调用：

```text
blender --background --factory-startup --python-exit-code 1 --python motion_previs_cli.py -- --spec motion.json --output result
```

可通过 `--previous-blend` 传入上次生成的工程以复用场景。后台只允许读取同一画布输出目录内的对应工程，加载时关闭文件内脚本自动执行。

画布正式输出仅有 `当前画布/videos/motion_*.mp4` 和 `当前画布/blender/motion_*.blend`，视频回填原节点。参数、检查记录与时间线保存在工程自定义属性及任务结果中；中间帧、海报、输入JSON、日志仅在系统临时目录中，结束或失败后清理，不加入画布资产。独立CLI的工作目录仍可生成诊断文件，由调用者决定保存策略。改参重跑遵循画布原有归档规则，不自动创建历史分组。

当前在Blender5.2.0 LTS验证。19项预设均检查了实际运动与关键帧数量；推近、横移、环绕、跟随已实际渲染；画布内生成、改参复用、播放、刷新恢复均有运行记录。采样检查不等于连续网格碰撞或成片审美认证。

## 旧工程兼容

旧版文本多镜头及镜头节拍尚未被单镜头预设协议完全覆盖。已有旧节点保留原模式与原文本；新界面不展示新旧模式选择器。编辑新运镜参数后才使用新协议。仅修改旧节点原提示词不会静默改成默认运镜。
