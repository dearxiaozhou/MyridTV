📌 三个改动点（确认后我改代码）
1. 节点开关只列暴露节点 — 当前 `renderComfyNodeModesControl` 列出 workflow 里全部 26 个节点，老王要的是用 `exposedNodes = new Set(config.fields.map(f => f.node))` 过滤一遍，只显示 3 个。
2. 宽高数值一行排 — `renderComfySettingField` 检测到 `field.type === 'number' && field.name === '数值'`（或更通用：相邻两个 number field）自动横排成 ``。
3. image/video/audio 输入字段从画布读 — 不再走 `pickComfyMedia` 上传，改成"输入节点绑定"：点击触发画布"连接模式"，选中任意 image 节点后，那张图作为输入喂给 `node.input`（如 `153.image`）。
