③ 这次跟之前比的关键变更
1. 节点开关：执/旁/禁 三态 → 开/关 两态
  之前：执 | 旁 | 禁 三按钮（旁=短路重定向、禁=级联删除下游）
  现在：开 | 关 单开关（关=Ctrl+B bypass）
  代码层面：run/bypass/mute 三模 → on/bypass 两模；mute 整条删。

2. 素材输入：上传按钮 → 上游节点计数
  之前：image/video/audio 字段显示"选择文件"上传按钮
  现在：去掉上传。画布里所有连入的 image node/audio node/video node 各自计数显示
  实现：扫画布 edges / selectedNode 连入关系，统计类型
  （"有一个就变 1"——你说的是这个意思）

3. 其它暴露节点：popover 下拉 → 主面板内 2 列网格
  之前：点击 pill 弹 popover，里面一行行开关
  现在：popover（图2）保留，但主面板里也直接平铺一份 2 列网格
  （pill 上点击也能继续开 popover，两种入口并存）

4. 整体版式：按你截图 1:1 复刻
  从上到下：缩略图标签 → 提示词 → 控制条 → 素材输入 → 宽高 → 其它节点 2 列
